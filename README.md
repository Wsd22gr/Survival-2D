# Survival-2D
Projekt gry 2D survival 
grafika:
   -2D styl terraria widok od boku
mechanizm:
   -gracz chodzi po swiecie open world generowanym w czasie rzeczywistym (wygenerowany już swiat jest zapisywany i można się do niego cofnąć chodząc w prawo a w lewo generowany jest nowy)w swiecie znajdą sie skrzynie/pułapki/potworki z ktorych dropią różne przedmioty typu miecz łuk zbroja itp.Gracz musi pamietac o uzupełnianiu jedzenia i wody oraz leczeniu po walce z potworami ,może on równierz craftować miecze itp poprzez zdobycie surowcow z dropow.
